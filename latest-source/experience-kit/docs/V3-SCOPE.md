# Version 3 scope

- 17 role-scoped service dashboards exist in the lab; demo and native data are separated. Reference code here is not the live system.
- Territorial atlas uses separate administrative/electoral views; historical representative and economic coverage contains source-dated gaps.
- Jos CCT is a fictional USD 1.5m planning and end-to-end demonstration with simulated payments.
- Android sample app: offline draft, demo PIN approval, ODK test sync. The demo PIN is not supervisor authentication. The iOS web preview is sample-only, local draft only, with no approval or sync.
- Screens, charts and links in the design package are editable click-through design states, not backend operations.
