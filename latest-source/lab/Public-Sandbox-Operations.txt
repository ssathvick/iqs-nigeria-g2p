START AFTER RESTART
Double-click Start-IQS-Public-Sandbox.bat in this folder, or the matching
desktop launcher. Allow several minutes for all platform services to start.
The existing Start-IQS-Nigeria desktop launcher also starts the connector.
Cloudflared is an enabled WSL systemd service and reconnects automatically.
This setup starts when Ubuntu/WSL starts, rather than at Windows sign-in.

AVAILABILITY
Keep the PC powered on, awake, connected to the internet, and the lab running.
Closing ChatGPT/Codex or a browser does not stop the services.
Shutdown, sleep, internet loss or WSL shutdown makes the sandbox unavailable.
Stop-Lab.ps1 stops WSL and therefore stops both local and public services.

TEMPORARILY STOP ONLY PUBLIC ACCESS
Run in PowerShell:
wsl -d Ubuntu-22.04 -u root -- systemctl stop cloudflared
Resume:
wsl -d Ubuntu-22.04 -u root -- systemctl start cloudflared
Starting the lab or restarting WSL enables public access again.

EXPOSED SERVICES
Programme management, modern registry, Odoo registry, staff portal,
beneficiary portal, workflows, master data, partner management, consent,
ODK, analytics, beneficiary programme administration and supporting APIs.
Keycloak staff/beneficiary sign-in endpoints are public; its administration
and master realm endpoints are blocked through the tunnel.
Kafka, MinIO console, Bridge/SPAR administration APIs and Odoo database
management remain outside the public routes. MinIO's authenticated object
API is available for application storage operations.
The environment uses synthetic records and simulated integrations.
