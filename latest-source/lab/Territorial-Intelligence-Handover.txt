Mapping rules
Administrative LGA-to-state membership comes from GRID3 publisher attributes. District-to-state association uses the NBS survey codebook a1b and state-name validation. These are separately typed relations in crosswalk; senatorial links set can_allocate=false. NBS survey codes and GRID3 LGA codes are NOT advertised as INEC delimitation identifiers.
No LGA/ward-to-constituency allocation is inferred. Electoral maps display containing-state context only. No constituency polygons or federal/State Assembly profile records are loaded. INEC PDF download attempts failed; unresolved layers are clearly disclosed.

Data quality
The NBS report repeats Osun West identically in D7. All 11 source columns were compared and one duplicate removed. Borno state and district poverty results are not representative and remain unranked. Survey CIs retained. Published tables were visually checked against rendered PDFs.
WorldPop assigned population: 205,620,462; unassigned boundary-mismatch population: 519,125; raster total: 206,139,587. Per-area rounding can cause a small rounding difference. Do not redistribute the unmatched population as observed data.
Five facility/LGA names remain unmatched (239 facilities); source-attributed state totals include them, LGA totals do not. Missing values are absent, never zero-filled. GRID3 facility data are non-exhaustive and not fully government-validated; counts do not assert facilities are functioning.
Reference years vary. No GDP, GVA, personal income, employment, causal multiplier, real-time treasury or national G2P coverage is fabricated. Planning scenarios are explicitly synthetic arithmetic and never modify published measures.

Public access and privacy
Static allowlisted package only: index, JS, CSS, data.json, states.geojson, lgas.geojson, measures.csv. No private registry APIs are called by the atlas. No household identifiers, names, phone numbers, bank details, household coordinates, credentials or sessions are published. Existing analytics API still returns 401 without authentication.
Nginx /territories/ uses a standalone presentation location to avoid authenticated application widgets; /territories redirects to the canonical HTTPS URL. Public files use no-cache. No authentication or authorization rule for other services changed.
