Open the sample-only field interface in Safari. This web preview saves one draft in that browser and does not support authenticated supervisor approval or server upload. Do not enter real personal information.

Open iPhone / iPad web app

  1. Open the web app above in Safari on the iPhone or iPad.
  2. Tap Share. On iPad, tap More or View More if needed.
  3. Choose Add to Home Screen; turn on Open as Web App if offered, then tap Add.
  4. Open the NSIPA Field icon from the Home Screen. Visit while online first to allow the preview to cache; offline operation varies by device and has not been verified on iOS.

See Apple’s instructions for iPhone and iPad.

Install and test

  1. Download the APK on the phone and open it. Android may ask you to allow installation from the app used to download it. Use your organisation’s security policy before installing.
  2. Open NSIPA Household Intake and select New sample visit. Enter a fictional enumerator ID, date and consent.
  3. In Area, search and select the state/FCT, LGA and ward. Optionally capture device GPS with permission (target accuracy: 50 metres, 30-second timeout) or enter latitude and longitude; open the coordinate in Google Maps if desired.
  4. Enter the household name and household head name in Home. Complete the other tabs with fictional data, save a draft, reopen it, and review it. The demonstration supervisor PIN is 246810; it is not an actual staff identity check.
  5. After demo approval, the record is queued locally. To test uploads, an administrator must securely provide an App User URL for the separate sample ODK Central project. Enter it under Sync settings; never share the URL publicly.
  6. Turn internet off, approve another fictional sample, and confirm it remains queued. Reconnect, open the approved sample and tap Upload this sample. Keep the app visible during the attempt. Launch, approval, reconnection and reboot do not start uploads. Leaving the app cancels the request. HTTP 201 marks the sample sent; errors require explicit retry. Check server receipt before retrying an uncertain outcome.

Do not use real names, identity numbers, bank details or other personal data. This test app is not general-purpose ODK Collect; it implements one fixed sample form.

Location reference
